# Contacts
Save a scanned or typed fingerprint under a name. The list is encrypted with the phone's Keystore key and never leaves the phone. Tap a contact to fill both the direct-peer and mesh-recipient fields; long-press to delete. Saving a name again replaces its fingerprint. A contact is only as trustworthy as the in-person verification done when saving it.

## Acceptance
Save two contacts, restart the app: both remain. Tap one: both fields show its fingerprint. Long-press: it disappears. Own fingerprint and short values are refused.
