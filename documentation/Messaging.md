# One application, two phones
The single native Android build contains radio discovery, identity, TLS and the encrypted local mailbox. No companion app, server or source download is needed by the end user. Store release is deferred, not built or signed. The web console is a developer tool, not the radio client. iOS requires a separate native transport; interoperability needs physical validation.

## Two-phone acceptance
After exchanging fingerprints, queue a message with data off and no group formed. Restart the app and view the same peer's messages: status must remain Queued. Form a Wi-Fi Direct group. Tap Exchange messages on the owner, then on the client. One exchange drains both queues in rounds of 16 (up to 256 messages each way). Delivered means a peer with the pinned key acknowledged durable receipt, not that a person read it. Drop a link before ACK: sender retries the same ID and recipient must show one entry. Wrong certificate: no delivery. Corrupt or oversized frame: no ACK. Clocks must agree; unsent messages expire after seven days, delivered and received history stays. The mailbox keeps the latest 256 messages: when full, the oldest delivered or received one is dropped; unsent ones never are. A message that arrives while the app is closed (background mesh relay) shows a "New message" notification without its text. Only direct foreground sessions; no background or multi-hop delivery. No physical results recorded.
